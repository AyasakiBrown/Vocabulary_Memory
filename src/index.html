Vocabulary Memory

雅思三个词库和 GRE 核心词汇合在一个 App 里 · 进度自动保存到本地一个文件，可与 IELTS Daily Tracker 同步。
菜单栏「词库」可切换页面；在「帮助 → 快捷键设置」中自定义键位。

🔤 字号
整体缩放,点一下立即全局生效(各词库 + 生词本都跟着变)。也可用菜单「显示」或自行设置的缩放快捷键。
数据保存在 ~/Library/Application Support/IELTSVocab/data.json —— 清浏览器缓存不会丢，备份这个文件即可迁移／恢复。
每个词库里 📊 统计 的「⬇️ 导出 / ⬆️ 导入」依旧可用，可把旧的浏览器进度导入进来。
